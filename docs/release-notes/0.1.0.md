# Pipesmith Registry 0.1.0

## Added

- `store add`, `scan`: attach file blob stores and directory trees, index them in SQLite.
- Read path under `/repository/<name>/...`. Formats:
  - Maven, groups with merged `maven-metadata.xml`.
  - npm package documents and tarballs, groups.
  - Docker registry API for pulls, one port per Docker repository.
  - PyPI, raw and every other format as stored files by path.
- `import`: users, roles, privileges, LDAP connections and realms from an export made with `tools/h2export.sh`.
- `import-state`: repositories from a repository settings list.
- Sign in with local users and LDAP, permissions on every route, sign in throttle, sessions in memory.
- Administration interface at `/`, read only: overview, browse, file detail, search, repositories, blob stores, users, roles, privileges, LDAP, realms.
- REST API under `/service/rest/v1`, read only. `GET /api/areas` lists the requests the server refuses.
- `serve --bind ADDR --server-names NAME[,NAME]`: network address once users are imported. Host check on every request.
- systemd `Type=notify`: `READY=1`, `WATCHDOG=1`, `STOPPING=1`.

## Not Included

- Uploads and deploys answer `405`. Changes through the REST API answer `501`.
- Proxy and group caching.
- Tokens for Docker and npm clients. Clients use Basic credentials.
- TLS.
- Changes to administration settings, log rotation, self update.
- A signature over `SHA256SUMS`.

## Not Run on a Linux Host

- The systemd unit.
- Network bind.
- Container image.

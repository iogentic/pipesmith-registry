# Pipesmith Registry 0.1.0

The first public release. Pipesmith Registry serves the file blob stores of an existing artifact repository install, read only, from one static binary.

## Contents

- Attach file blob stores and plain directory trees with `store add`, and index them with `scan`.
- Maven repositories and groups, with `maven-metadata.xml` merged across group members.
- npm package documents and tarballs, groups included.
- Docker pulls through the registry API, on one port per Docker repository.
- PyPI, raw and every other format as stored files by path.
- Import of users, roles, privileges, LDAP connections, realms and repositories from an export of the old database (`tools/h2export.sh`, `import`), or of the repositories alone (`import-state`).
- Sign in with local users and LDAP, permissions on every route, a sign in throttle and sessions in memory.
- An administration interface at `/`: overview, browse, file detail, search, repositories, blob stores, users, roles, privileges, LDAP, realms. Every screen only reads.
- A REST API under `/service/rest/v1` for reads.
- `serve --bind <address> --server-names NAME[,NAME]` serves on a network address once users are imported. Every request passes a Host check.
- Readiness, watchdog and stopping are reported to systemd (`Type=notify`).
- Binaries for linux-amd64, linux-arm64 and darwin-arm64, a container image, SBOMs in SPDX and CycloneDX, and a `SHA256SUMS`. This release is not signed; signed releases come with the self update.

## Not Included

- Uploads and deploys answer `405`, changes through the REST API answer `501`.
- No proxy or group caching.
- No tokens for Docker and npm clients; they use Basic credentials.
- No TLS.
- No changes to administration settings, no log rotation, no self update.

## Not Run on a Host

The systemd unit, the network bind and the container image have not run on a Linux host yet.

## Verify

Check the checksum of the binary against `SHA256SUMS`. The commands are in the README and in the manual at https://mirosso25.github.io/pipesmith-registry/.
